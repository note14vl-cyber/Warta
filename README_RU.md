# Room Explorer 3D — исправление ориентации и диагностика запуска

Проект для Godot 4.4.1. Android workflow сохранён.

## Исправлено в этой версии
- Ориентация Android выставлена в Landscape (`0`) и в `project.godot`, и в Android export preset.
- Добавлены диагностические сообщения в `_ready()`, чтобы в логе Godot было видно, начал ли выполняться главный скрипт и дошёл ли он до создания интерфейса.
- Для корневого узла объектов задан явный тип `Node3D`, чтобы избежать неоднозначного вывода типа при создании StaticBody3D/Node3D.
- Сохранены текущие сцена, текстуры, управление, EDIT, LIGHTING, предметы и Android workflow.

## Важно
Это исправление конфигурации ориентации и диагностическая сборка, а не подтверждённый рабочий APK. В доступной среде нет исполняемого Godot 4.4.1, поэтому проверить запуск сцены и компиляцию GDScript здесь невозможно. Не считайте синий экран устранённым до успешного запуска APK на устройстве.

## Если снова будет синий экран
В GitHub Actions откройте шаг `Import project` и скопируйте первую ошибку Godot (строку `SCRIPT ERROR`, `Parse Error` или `ERROR`). Именно она нужна для точного исправления. Сообщения `Room Explorer: _ready started` и `Room Explorer: world, player and UI initialized` помогут понять, выполняется ли главный скрипт.
